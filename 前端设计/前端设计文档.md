# Studyield 前端设计文档

> 基于 `frontend/src` 源码分析生成 | 框架: React 19 + TypeScript + Vite + TailwindCSS

---

## 一、项目概述

Studyield 是一个 AI 驱动的学习平台，前端采用单页应用 (SPA) 架构，主要路由分为两大部分：

- **公开区 (Public)** — 营销落地页、博客、认证页面，使用 `PublicLayout`
- **控制台 (Dashboard)** — 登录后的核心功能，使用 `DashboardLayout`（侧边栏 + 顶栏布局）

路由保护：通过 `ProtectedRoute` 包裹，未登录跳转 `/login`；新用户未完成引导则跳转 `/onboarding`。

---

## 二、技术栈

| 层级 | 选型 |
|------|------|
| 框架 | React 19 + TypeScript |
| 构建 | Vite |
| 样式 | TailwindCSS + `framer-motion` 动画 |
| 路由 | React Router v6 |
| 状态管理 | Zustand (`useFlashcardsStore`, `useStudySetsStore`, `useGamificationStore`, `useLiveQuizStore`, `useNotesStore`, `useProblemSolverStore`, `useNotificationsStore`) |
| HTTP | Axios + `api.ts` 拦截器（JWT Token 自动注入、401 自动刷新） |
| 流式通信 | SSE (EventSource) / Fetch Stream / WebSocket (Socket.IO) |
| 图表 | Recharts（折线图、饼图、柱状图） |
| 国际化 | react-i18next（多语言支持 `locales/`） |
| UI 基础组件 | 自建 shadcn 风格组件 (`components/ui/`) |
| 认证 | JWT + Google/Apple OAuth |

### 4.3 学习集模块 (Study Sets)

#### 4.3.1 StudySetsPage — 学习集列表
**路由**: `/dashboard/study-sets`

- 网格/列表切换展示
- 搜索（标题/标签）
- 标签筛选
- 公开/私有限定
- 分页加载
- 空状态引导创建

#### 4.3.2 CreateStudySetPage — 新建学习集
**路由**: `/dashboard/study-sets/create`

- 表单：标题（必填）、描述、标签、封面图、考试日期、考试科目
- 公开/私有切换
- 创建后跳转到详情页

#### 4.3.3 StudySetDetailPage — 学习集详情
**路由**: `/dashboard/study-sets/:id`

- **功能 Tab 分区**:
  - **闪卡列表** — 分页展示，支持按标签/复习状态筛选和排序；每张闪卡显示正反面、状态（New/Learning/Review/Mastered）、下次复习时间；支持内联编辑和删除
  - **测验** — 已生成测验列表（分数/时间），一键开始 AI 生成测验
  - **学习计划** — 间隔重复学习进度 + 考试倒计时(`StudySchedule`)
  - **笔记** — 笔记列表，支持置顶、颜色标记
  - **文档** — 已上传的学习资料列表
  - **思维导图** — 从笔记自动生成 (`MindMapView`)
  - **知识来源** — 关联的外部资料 (`SourcesTab`)
- **统计概览** — 饼图 (闪卡掌握状态分布)、柱状图 (每日复习量)
- **操作**：编辑、删除（带确认弹窗）、分享

#### 4.3.4 EditStudySetPage — 编辑学习集
**路由**: `/dashboard/study-sets/:id/edit`

- 与创建表单结构相同，预填已有数据

#### 4.3.5 StudySessionPage — 间隔重复学习
**路由**: `/dashboard/study-sets/:id/study`

- 只展示到期卡片
- SM-2 算法间隔重复
- 兼容三种卡片类型：
  - **标准卡** — 正面问题 → 点击翻转 → 自评 1-5
  - **完形填空** — 隐藏 `{{答案}}` 标记内容，点击揭示
  - **图片遮挡** — 标注遮挡区域，点击揭示
- 学习进度条、剩余卡片数
- 完成时统计正确率 + XP 奖励

#### 4.3.6 AddFlashcardPage / EditFlashcardPage
**路由**: `/dashboard/study-sets/:id/flashcards/add` 和 `.../:flashcardId/edit`

- 三种卡片编辑器：
  - `FlashcardEditor` — 标准正反面编辑器
  - `ClozeEditor` — 完形填空编辑器
  - `ImageOcclusionEditor` — 图片遮挡编辑器（上传图片 → 画矩形标注遮挡区）
- AI 辅助生成（"AI 帮我写" 按钮）
- 支持 LaTeX 数学公式（KaTeX）
- 标签管理

#### 4.3.7 QuizPage — AI 生成测验
**路由**: `/dashboard/study-sets/:id/quiz`

- 从学习集内容生成测验
- 题型：多选题 / 判断题 / 简答题 / 填空题
- 可配置题目数、题型分布、时间限制
- 作答界面：逐题展示，倒计时
- 提交后显示分数、每题正误、解析
- 历史尝试记录

#### 4.3.8 MatchGamePage — 配对游戏
**路由**: `/dashboard/study-sets/:id/match`

- 将术语和定义打乱为网格卡片
- 翻牌配对玩法
- 计时 + 计步
- 完成动画 + XP 奖励

### 4.5 实时竞赛模块 (Live Quiz)

**路由**: `/dashboard/live-quiz`, `/dashboard/live-quiz/:code`, `/dashboard/study-sets/:id/live-quiz`

- **三种入口**：
  1. 创建新房间（从学习集生成题目）
  2. 通过房间码加入已有房间
  3. 直接输入码加入
- **阶段流转**：
  - **LobbyPhase（大厅）**：显示房间码、复制按钮、玩家列表、房主"开始"按钮
  - **QuestionPhase（答题）**：倒计时、选项、进度条（第N/总题数）
  - **ScoreboardPhase（排行榜）**：每题结束后排名展示
  - **ResultsPhase（结果）**：最终排名、奖牌动画
- WebSocket 实时通信

### 4.7 题目求解器模块 (Problem Solver)

#### 4.7.1 ProblemInputPage — 输入入口

  - 文本输入（富文本 textarea）

#### 4.7.2 SolvingProgressPage — 求解进度
**路由**: `/dashboard/problem-solver/solve/:id`

- 实时展示三代理处理进度（SSE 流式输出）

- 每阶段显示 Agent 推理过程、置信度
- 最终答案展示 + 正误判断

#### 4.7.3 SolutionPage — 解决方案详情

#### 4.7.4 SimilarProblemsPage — 相似题目

#### 4.7.5 StudyBuddyChatPage — AI 辅导对话

### 4.8 Teach-Back 模块 (费曼教学法)

**路由**: `/dashboard/teach-back`

- 创建方式：

- 发现误解、优点、改进建议
- **AI 挑战模式**：模拟质疑者对话，用户需辩护自己的理解

## 十、设计特点总结

1. **布局统一** — 公开页用 `PublicLayout`，控制台用 `DashboardLayout`（左侧边栏常驻 + 移动端抽屉式）
2. **动画丰富** — 全站使用 `framer-motion` 做入场动画、过渡效果
3. **状态管理分层** — Zustand stores 按业务域拆分，配合 React Context (`AuthContext`) 管理全局认证状态
4. **多输入方式** — 支持文本、图片拖拽、拍照、语音四种问题输入
5. **AI 深度集成** — 几乎每个功能模块都有 AI 辅助生成能力
6. **流式通信** — 对话、求解进度、研究进度均采用 SSE/Fetch Stream 实现实时流式输出
7. **实时协作** — 竞赛、协作考试通过 WebSocket (Socket.IO) 实现
8. **游戏化设计** — XP/等级/徽章/排行榜/连续打卡贯穿全平台
9. **三种闪卡类型** — 标准 / 完形填空 / 图片遮挡，各有独立编辑器和查看器
10. **移动端适配** — 侧边栏抽屉式、响应式网格、触摸友好的交互
